    Analítica de datos

    De los datos a las decisiones

    Análisis hechos en Google Colab para la materia de Analítica de Datos, explicados sin tecnicismos.

    ¿Se puede predecir el tamaño de una flor a partir de sus otras medidas?

    Con 150 flores reales del conjunto de datos Iris entrené un modelo de machine learning que calcula el largo del pétalo usando las otras tres medidas. Luego lo probé con flores que nunca había visto.

    2,4 mmde error promedio
    97 %de la variación explicada
    7×más preciso que adivinar
